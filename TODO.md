# DRISHTI — Demo Outcomes

- [x] **Presentation-ready disaster control-room dashboard.** Build a professional, visually impressive modern dashboard in React using a dark navy background, modern dashboard layout, clean charts, cards, icons, status indicators, alerts and legends. Use red for critical zones, orange for high risk, yellow for medium risk and green for safe routes. Open directly with sample disaster data already loaded so the presentation can start immediately without setup or configuration.
- [x] **Live Disaster Map and Isolation Predictor.** Display a simulated flood scenario around Sullia and Belthangady, Karnataka, on an interactive Leaflet map using OpenStreetMap. Show villages, hospitals, shelters and rescue teams; mark flooded and blocked roads; highlight isolated villages in red. Add buttons to block and reopen roads. When a road is blocked, demonstrate how nearby villages become isolated and display their accessibility status.
- [x] **Silent Area Detection and Rescue Priority.** Show high-risk villages with zero emergency reports and display alerts such as “HIGH RISK – NO REPORTS – NEEDS VERIFICATION”. Display a ranked list of affected villages with priority scores, risk levels, confidence percentages and explanations of why each village needs attention.
- [x] **Offline Mesh Relay Demo.** Create a visual demonstration of an offline mesh relay showing emergency messages hopping between villages, responders, shelters or relay nodes when regular connectivity is unavailable.
